## Calculadora CLI

Execute `node src/calculator.js 2 + 3` para somar. As operações disponíveis são
`+`, `-`, `*` e `/`; coloque `*` entre aspas para evitar expansão pelo shell:
`node src/calculator.js 45 '*' 2`. Execute os testes com `npm test`.
